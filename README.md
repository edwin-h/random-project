# random-project

A sandbox repository for experimenting with Git workflows and small web snippets.

## Purpose

This repo is a low-stakes place to:

- Practice commits, branches, and pushes
- Try out small HTML/CSS/JS experiments
- Test tooling and automation without affecting real projects

## Getting Started

```bash
git clone <repo-url>
cd random-project
```

Static files like `.html` pages can be opened directly in a browser:

```bash
open index.html
```
